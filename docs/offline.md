# Offline Listening

Bookstory supports per-item offline downloads and automatic progress sync when online.

## What users can do

1. Download individual items for offline playback.
2. Remove offline files per item.
3. Remove all offline files from Settings.
4. Queue progress while offline and sync later.

## Offline settings

- Default volume
- Max offline storage in MB (`0` means unlimited)
- Auto-download when playback starts
- Auto-remove offline files when finished

## Behavior notes

- Remove actions are only shown for items with offline files.
- Playback prefers local offline audio when available.
- If storage limit is exceeded, oldest downloads are removed first.
